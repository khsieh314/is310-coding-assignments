## Perseus Digital Library
Perseus Digital library hold a lot of value to modern students slogging through ancient texts. It holds a variety of ancient Greek and Roman classic texts and their translations as well as a several other texts. It's helpful becuase if you are reading a particularly difficult passage you can click on a word to see it's etymology. 
The Perseus Digital Library is put forth by Gregory Crane, a professor Tufts University, in 1987. Perseus 1.0 were made with help from Yale Univeristy on CD-ROM mainly focusing on the Greek alphabet. Several other verison were released before it finally made it online.
Java is the main coding source incorporating JPEG and XML as it's mark up language. All the content has been posted to SourceForge for use (see image below). When going through the SourceForge the file path I found was .tar.gz. The .tar is a bundle of files all together which makes sense becuase they are dealing with a lot of content. the .gz represent a sort of zipped file. It's gone through several variations, the newest being Perseus 4.0/Hopper. It follows the stoa conventions for it's markup langauge.
